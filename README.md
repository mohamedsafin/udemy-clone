# udemy-clone
📘 Udemy Clone Website (HTML & CSS – Flexbox)
This project is a responsive Udemy Clone website built using pure HTML and CSS, with Flexbox for layout design. The goal of this project was to practice modern front-end layout techniques and recreate the structure of a real-world e-learning platform.
🚀 Features


Clean and user-friendly UI inspired by Udemy


Responsive layout using CSS Flexbox


Course cards with images, titles, instructors, ratings, and prices


Navigation bar and category sections


Well-structured and readable HTML


No frameworks or libraries used (Beginner-friendly)


🛠️ Technologies Used


HTML5


CSS3


CSS Flexbox


🎯 Purpose of the Project
This project helped me:


Understand Flexbox concepts (row, column, alignment, spacing)


Improve layout and UI structuring skills


Practice cloning a real-world website design


Strengthen front-end fundamentals




Customize it based on your experience level (student/fresher)
